# Contributing

Bug reports, reproducible game-configuration reports, documentation and patches are welcome.
Run `source/build.sh test` and `python3 source/tools/publication.py check` before submitting changes.

Contributions to MacGaming's original files are provided under GPL-3.0-or-later.
Preserve existing third-party notices and identify the origin and exact license of
any imported code. Do not submit game assets, proprietary SDK material or code
whose redistribution permission is unclear.

Use a public display name or pseudonym and an appropriate private/noreply commit
email if you do not want personal details in public Git history. Git records author
and committer identities. Do not copy a private development repository's `.git` folder.

For compatibility reports, include the game edition/store, game build, runtime
version, renderer, macOS version and reproducible steps. Distinguish reaching a menu
from gameplay, and short gameplay from save/reload and a sustained session.

Review diagnostic reports before posting. Never upload account files, login tokens,
raw process environments, saves, crash dumps or unreviewed logs. Remove personal
paths and identifiers. Financial support never requires publishing private data.
